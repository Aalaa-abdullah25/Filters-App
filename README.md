# 🖼️ Image Filter App

This is a simple web-based application built with **Streamlit** and **OpenCV** that allows users to upload an image and apply various image filters in real-time.

## 🚀 Features

- 📤 Upload images (`.png`, `.jpg`, `.jpeg`)
- 🖤 Convert image to Black & White
- 🔆 Adjust Brightness
- 🎨 Stylize images using cartoon-style filter
- ⚡ Apply HDR effect
- 📜 Vintage photo effect
- Live preview of both original and filtered images

## 🛠️ Technologies Used

- [Python](https://www.python.org/)
- [OpenCV](https://opencv.org/)
- [Streamlit](https://streamlit.io/)
- [NumPy](https://numpy.org/)
- [Pillow (PIL)](https://pillow.readthedocs.io/)
